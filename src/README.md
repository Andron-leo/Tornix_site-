# TORNIX — сайт цеху ЧПУ

Сайт металообробки: токарка, фрезер, заявка з креслення, калькулятор маси, сторінка для замовників з ЄС.

## Що потрібно

- [Node.js](https://nodejs.org/) версії 22 або новішої
- npm (йде разом із Node)

## Запуск на комп’ютері

1. Розпакуйте архів.
2. У терміналі зайдіть у папку проєкту.
3. Встановіть залежності і запустіть:

```bash
npm install
npm run dev
```

4. Відкрийте в браузері адресу, яку покаже термінал (зазвичай порт 8080).

Збірка для хостингу:

```bash
npm run build
```

## Викласти для колег (без домену)

Сайт не відкриється як папка HTML. Потрібен хостинг із Node.

### Netlify (безкоштовно, адреса `щось.netlify.app`)

1. Завантажте цей архів, розпакуйте.
2. Створіть репозиторій на [github.com](https://github.com), залийте файли всередині папки (`package.json`, `src`, …).
3. Зайдіть на [app.netlify.com](https://app.netlify.com) → Sign up with GitHub.
4. **Add new project** → Import from Git → цей репозиторій.
5. Build command: `npm run build`. Publish directory: `dist/client`. Node 22.
6. Deploy. Кидаєте колегам посилання `….netlify.app`.

Не використовуйте Netlify Drop (перетягнути папку) — цей сайт так не заведеться, потрібна збірка.

### Vercel (теж без домену, `щось.vercel.app`)

Той самий репозиторій → [vercel.com](https://vercel.com) → Import. Нічого не міняти.


## Що всередині

| Сторінка | Зміст |
|---|---|
| `/` | Головна цеху |
| `/cnc` | Послуги |
| `/orders` | Як замовити |
| `/eu` | Для замовників з ЄС |
| `/calculator` | Маса заготовки |
| `/quote` | Заявка |

Заявки зберігаються в браузері (localStorage). Щоб вони приходили на пошту — підключіть форму до email або CRM окремо.

Контакт, місто й телефон у футері зараз загальні — підставте свої в `src/components/site-shell.tsx`.
